# 반도체 팹 시뮬레이터 — 개발 6단계

PC 전용 Vite + Three.js + 순수 JavaScript. 스테이지 0~11(세정부터 금속 패터닝, 최종 전기적 테스트·등급·보고서 저장까지)을 구현합니다. 외부 배포는 실행하지 않았습니다.

## 실행

Node.js 22.12 이상 또는 20.19 이상. 이 파일이 있는 폴더에서:

```sh
npm ci
npm run dev
```

표시된 Local 주소를 브라우저에서 엽니다. HTML 파일을 더블 클릭하지 않습니다.

```sh
npm test
npm run build
npm run preview
```

빌드는 `dist/`. `base: './'`이므로 GitHub Pages 저장소 하위 경로를 지원합니다. `npm ci` → `npm run build` 후 dist를 Pages 아티팩트로 배포합니다.

## 조작

WASD/방향키 또는 바닥 클릭: 이동. ‘다음 장비로 이동’: 안내 장비까지 경로 이동. E/장비 열기: 상호작용. R: Runsheet. C: 단면도. Esc: 패널 닫기. 패널을 여는 동안 이동 정지.

마스크 정렬 보드를 클릭한 뒤 방향키로 X/Y, Q/E로 회전합니다. 슬라이더로도 조절할 수 있습니다. 기준 십자(청록)와 마스크(자주)를 맞추고 노광량을 입력하여 실행합니다. 정렬은 자동으로 맞춰지지 않습니다.


## 돌발 상황 퀘스트 INCIDENT 001: 누가 산화막을 망쳤을까?

Runsheet(R) → 새 Lot 시작 → "퀘스트로 새 Lot 시작"을 누르면 Field 산화 공정에 숨은 장비 문제가 생깁니다. 교육용 가상 시나리오이며 실제 사고 기록이 아닙니다.

- 숨은 원인 3가지 중 하나가 퀘스트 시작 시각을 시드로 정해집니다(저장 후 불러와도 동일).
  - A 계측기 편향: 측정 장비가 목표 두께의 약 13%만큼 두껍게 읽음. 실제 막은 정상.
  - B 산화로 과성장: 단계 타이머 고장으로 레시피 60분이 실제 72분 가동. 실제로 약 13% 두꺼움.
  - C 국부 두께 이상: 남쪽 지점만 16% 두껍게 성장. 평균은 거의 정상.
- 흐름: 측정 → OOS 경고(평균 또는 지점별 ±10% 이탈) → Lot HOLD → 증거 수집 → 원인·조치 판정(한 번만 채점) → 조치 실행.
- 증거와 시간: 기준 시료 측정 6분(편향만 드러남), 산화로 공정 로그 5분(타이머 이상만 드러남), 5점 재측정 10분(국부 이상만 드러남). HOLD 이후 조사 시간이 20분을 넘으면 1분당 0.5점 감점.
- 점수(100점): 원인 정답 60 + 조치 20(최선 20, 가능하지만 비용 큼 10) + 핵심 증거 확인 20 − 시간 감점.
- 조치: 편향 → 교정 후 재측정해서 합격하면 서명. 과성장·국부 이상 → MRB 특채(Field 산화막이 두꺼워진 것이라 소자 분리에 큰 문제가 없음)로 결함 인지 서명, 또는 Lot 폐기.
- C에서 중앙 1점만 측정하면 경고가 뜨지 않고, 그대로 서명하면 "놓친 결함"으로 기록됩니다.
- OOS 경고·HOLD 중에는 서명할 수 없습니다. 결과는 최종 전기적 테스트 화면과 Runsheet 보고서에 남습니다.
- `qa-metrology.html`의 퀘스트 A/B/C 버튼으로 각 원인을 바로 확인할 수 있습니다.

검증 필요: 편향 13%, 타이머 1.2배, 국부 1.16배, 시간·배점은 교육용 설정입니다. 일반 Lot의 장비는 정상 상태라 공정 런 간 산포는 아직 없습니다.

## 정밀 계측 (참값과 관측값 분리)

두께 공정(Field 산화, 게이트 산화, Poly·ILD·Al 증착)은 공정 장비가 실제 두께를 알려주지 않습니다. 두께 측정 장비에서 직접 측정해야 합니다.

- 측정 지점(중앙·북·동·남·서)을 웨이퍼 지도나 체크박스로 고릅니다. 지점당 2분. 1점만 재면 균일도를 판단할 수 없고, 불균일한 막을 놓칠 수 있습니다(테스트로 확인).
- 관측값 = 참값 + 장비 편향 + 반복 오차(1σ = max(0.3 nm, 두께×0.2%)). 산화막은 위치별 비(평균 1.000)로 지점별 참값을 만듭니다.
- 장비 편향은 측정 1점마다 0.08 nm씩 쌓입니다(드리프트). 편향은 직접 보이지 않으므로 인증 기준 시료(SiO₂ 100.0 nm, 3회 반복, 6분)로 확인하고, 교정(15분)으로 초기화합니다.
- 재측정이 가능하고 측정 이력이 남습니다. 합격·서명 판정은 마지막 측정값 기준입니다.
- 실제 두께는 공정 장비 화면, 단면도 숫자, Runsheet에서 숨기고 측정값만 보여줍니다. Lot 완료 후 전기적 테스트 화면의 "사후 분석: 측정값 vs 실제 값"과 최종 보고서에서 공개합니다.
- 난수는 Lot 첫 기록 시각과 계측 순번으로 시드를 정하므로, 저장 후 다시 불러와도 같은 값이 나옵니다.
- `qa-metrology.html`: 개발 서버에서 산화막 측정과 불균일 Poly 측정 화면을 바로 확인하는 검증용 페이지입니다.

한계(검증 필요): 반복 오차·드리프트·기준 시료 수치는 교육용 가정입니다. 일반 Lot에서는 공정 런 간 산포가 없어서 증착 전 "예상 분포"가 실제 값과 같습니다. 장비 고장에 의한 차이는 돌발 상황 퀘스트에서만 생깁니다.

## 6단계: 3D 비주얼

- Bay별 바닥 색을 서로 구분되게 바꾸고(확산 살구색, Photo 노랑, 식각 파랑, 주입 보라, 박막 초록, 계측 하늘색, 테스트 모래색), 테두리 선과 바닥 Bay 이름을 표시합니다.
- Photo Bay: 뒷벽 노란 패널, 발광 띠, 천장 노란 형광등 2줄, 노란 포인트 조명 1개. 실제 포토 공정실의 노란 조명(감광제의 단파장 노출 방지)을 표현합니다.
- 장비 이름 라벨(HTML)은 기존과 같고, 다음 목적지 라벨은 테두리로 강조됩니다.
- 다음 목적지: 장비 위에서 회전하며 위아래로 움직이는 화살표 + 바닥 링 + 캐릭터 발밑 방향 화살표(가까워지면 숨김).
- 장비 신호등(위에서 빨강·주황·초록): 대기 = 흐린 초록, 다음 목적지 = 밝은 초록, 실행 직후 2.6초 = 빠른 주황 점멸, 계측·서명 대기 = 주황 점멸, 검사 불합격 = 빨강 점멸. 상태 판정은 `systems/equipmentStatus.js`(테스트 포함)입니다.
- 성능: 그림자·후처리 없이 기본 재질만 사용합니다. 시작 2.5초 뒤부터 평균 프레임이 약 32 fps 아래로 2초 이상 떨어지면 자동으로 단순화합니다(픽셀 비율 1, 바닥 격자·Photo 포인트 조명 끔). 패널이 열려 있는 동안은 6프레임에 한 번만 렌더링합니다. 주소 뒤에 `?quality=low`를 붙이면 처음부터 단순화 모드로 시작합니다.
- 설정값은 `src/constants.js`의 `VISUALS`에 있습니다.

## 5단계: 전기적 테스트 · 등급 · 보고서 (스테이지 11)

전기적 테스트 장비에서 ‘Vt · Id–Vg 측정 실행’ → 결과 확인 → 최종 서명 → 전체 Runsheet 저장 순서입니다.

- 측정 조건: 300 K, Vds = 1 V, Vg = 0~3.3 V, 67점 스윕 (process_flow.json의 testConditions).
- Vt: Vfb + 2φF + Qdep/Cox. Vfb = φms − qQf/Cox이고, S/D 인 주입이 패터닝된 Poly 게이트도 함께 도핑하므로 n+ Poly 게이트로 보고 φms = −(Eg/2 + φF)를 씁니다. 기판 1e16 cm⁻³·게이트 산화막 약 14 nm에서 φms ≈ −0.917 V, Vt ≈ 0.00 V입니다. 실제 공정의 Vt 조정 주입(채널 붕소 주입)은 아직 없어서 Vt가 0 V 근처로 나오며, 화면에 이 점을 안내합니다. 산화막 두께(Cox)와 기판 도핑이 Vt를 바꾸고, S/D 도즈는 Vt가 아니라 직렬 저항과 전류에 영향을 줍니다.
- Id–Vg: 장채널 제곱 법칙 + S/D 면저항·Contact·Al 배선의 직렬 저항을 반복 계산으로 반영합니다. 유효 채널 폭/길이에는 Gate 정렬·측면 식각·박리가 반영됩니다.
- 연결 불량(Contact 잔사, 금속 잔사, Poly 잔사 등)이면 단자 전류를 만들어내지 않고 ‘산출불가’와 F 등급으로 표시합니다.
- 기준 소자: 같은 공정 흐름을 목표 조건 그대로 자동 실행한 Lot과 비교합니다.
- 등급: 100점에서 Vt 이탈(최대 25), Ion 이탈(최대 30), 막 균일도 악화(최대 10), 불합격 검사(건당 3, 최대 15), 재작업 감점을 뺍니다. S ≥ 90·A는 스펙(Vt ±0.15 V, Ion ±20%) 충족이 필요하고, 연결 불량이나 큰 이탈(Vt ±0.3 V, Ion ±50% 초과)은 F입니다.
- 공정 영향 피드백: 공정 그룹 하나만 기준값으로 되돌렸을 때 Vt·Ion이 얼마나 바뀌는지 비교해 순위를 매깁니다. 합산 가능한 인과 기여도나 수율 확률이 아닙니다.
- F 등급은 결과 확인 체크 후 서명할 수 있습니다. 서명 후 PDF(A4 가로) 또는 페이지별 PNG 묶음(zip)으로 결과 요약·곡선·피드백·전체 Runsheet를 저장합니다. Runsheet(R)에서도 저장할 수 있습니다.
- `qa-electrical.html`: 개발 서버에서 기준 소자와 Contact 불량 소자 화면을 바로 확인하는 검증용 페이지입니다.

변경 이력: 이전 버전은 Vfb = 0 V로 두어 Vt를 약 0.91 V로 과대평가했습니다. n+ Poly 일함수 차이를 반영해 수정했습니다.

검증 필요: 고정 산화막 전하 Qf = 0(실제 열산화막은 약 1e10~1e11 cm⁻²로 Vt를 더 낮춤), 고정 채널 이동도, 기판 도핑 1e16 cm⁻³, Contact 저항, 등급 가중치는 교육용 가정입니다. 서브스레숄드 전류, 게이트 누설, 채널 길이 변조, 단채널 효과는 생략했습니다.

### 증착률과 균일도 체험

- Poly: 기준 10 nm/분@620°C. 기준 온도 주변 Arrhenius 반응속도. 온도와 시간, 온도 분포 폭을 입력합니다.
- Al: 기준 100 nm/분@200 W. 파워에 비례한 증착률 근사. 파워·시간·기판 회전 켬/끔을 입력합니다.
- 입력 중 평균/최소/최대 두께와 5지점(중앙·북·동·남·서) 예상 지도가 즉시 갱신됩니다. 실행 전 예상값과 실행 후 계측 기록은 구분됩니다.
- 비균일도=(최대−최소)/(2×평균)×100. 작을수록 고릅니다. 기준 Poly 약 2.09%, Al 4%입니다. 회전 없는 Al은 12%입니다.
- 시간을 2배로 하면 평균·최소·최대 두께는 2배가 되며 상대 비균일도는 그대로입니다. 시간만 늘려서 불균일을 고칠 수 없습니다.
- 온도 분포 폭을 키우면 Poly 지점별 편차가 커집니다. Al 회전을 끄면 공간 편차가 커집니다.
- 평균 목표 ±10%와 비균일도 Poly ≤5%, ILD/Al ≤6%를 판정합니다. 추가 증착은 기존 5지점 두께에 누적됩니다.
- 5지점은 동일 면적 가중의 결정론적 교육용 분포입니다. 실제 전면 균일도·무작위 런 간 산포·측정 노이즈는 미구현입니다.
- 후속 식각은 평균값 대신 각 지점의 실제 두께를 사용합니다. 평균 두께/식각률만큼 처리해도 두꺼운 지점에는 잔사가 남을 수 있습니다.

### 주입·어닐링과 후속 공정 누적

P의 Rp/ΔRp는 Illinois 표의 10·20·50·100 keV 행을 선형 보간합니다. 50 keV에서 Rp=60.7 nm, ΔRp=25.6 nm입니다. 가우시안 농도와 확산 폭 sqrt(ΔRp²+2Dt), 활성화율, 접합 깊이, 면저항 1/(q μ 활성 도즈)를 계산합니다. 산화막 투과 감소, Gate 패턴 품질이 유효 주입·검사에 반영됩니다. 활성화 농도 그래프는 HTML 내 SVG입니다.

선택비=대상막 식각률/PR 또는 하부막 식각률. Poly·Contact·Metal의 5지점 잔류막과 보호부 손실, 하부 손실, 박리·정렬 상태를 기록합니다. Contact 불량은 Al 증착 검사에도 이어집니다. 단면은 PR/Metal/ILD/Poly/SiO₂/Si와 n+ 영역을 표시합니다. Contact·배선은 대표 개념도이며 완전한 회로 레이아웃 시뮬레이션은 아닙니다.

Gate·Contact·Metal 포토 재작업은 현재 마스크 식각 전에 코터에서 실행합니다. 해당 마스크의 이전 기록만 이전 이력으로 남기고, 앞 공정의 막과 검사 기록을 보존합니다. 식각 후 재작업은 차단합니다. PR 제거는 막 두께·이미 발생한 패턴 결함을 지우지 않습니다.

### 4단계 상수 출처와 한계

- Poly 기준률은 DTU POLY620의 약 10~12 nm/분, wafer 내 편차 자료를 참고했습니다. 10 nm/분 기준점, 1.5 eV 활성화에너지, 온도 편차 모델은 교육용 보정이며 **검증 필요**입니다. 결정성·가스 유량·압력·보트 위치·응력 변화는 미반영입니다.
- Al 파워-증착률 관계의 기준값과 균일도 계수, LTO 50 nm/분@400°C, 선택비·손상/합격 경계는 **검증 필요**입니다. 스퍼터 실제 형상·타겟 수명·압력·스텝 커버리지·재스퍼터는 미반영입니다.
- 활성화 운동학·고정 이동도 100 cm²/Vs·기판 도핑 1e16 cm⁻³·산화막 투과 모델은 **검증 필요**입니다. 채널링·TED·농도 의존 이동도·고용도 제한·실제 n형 Poly 도핑은 미반영입니다.
- 게이트 산화는 초기 건식 성장 보정이 없는 동일 Deal–Grove를 사용하므로 약 14.2 nm는 교육 모델 값으로 **검증 필요**입니다.
- 모든 숫자 상수와 출처는 src/constants.js, 목표·작업 순서는 process_flow.json. 증착 목표 두께도 JSON으로 지정합니다.

### 저장 호환과 구현 경계

기존 3단계 완료 저장은 스테이지 4의 PR 제거부터 이어집니다. 저장 키를 유지하고 실제 명령을 새 모델로 재실행하여 복원합니다. 3D는 기존 코드를 유지했습니다. 새 순수 모델은 systems/fabrication.js, 증착 예상/5지점 지도·도펀트 그래프는 ui/fabricationPanels.js에 있습니다. tests/fabrication.test.js는 전체 JSON 흐름·누적·측정 잠금·마스크별 재작업·저장 복원을 검사합니다.

아래는 기존 0~3단계의 상세 설명입니다.

## 0~3단계 플레이 흐름

1. 습식 벤치(기존 식각기 공용)에서 웨이퍼 입고·RCA 세정 완료, 확인 서명.
2. 산화로에서 습식 1000°C·60분. 약 375.6 nm 성장. 계측기에서 두께를 재고 서명해야 다음 단계.
3. 코터에서 HMDS 처리 또는 생략을 선택해 기록.
4. 코터에서 3000 rpm 코팅: PR 1500 nm. 소프트베이크 100°C/60초는 고정 조건 자동 처리.
5. 노광기에서 마스크 정렬. 허용 최대 오차 1 µm. 100 mJ/cm² 노광. 불량 정렬로도 실행 가능하며 결과가 기록됨.
6. 코터·현상기에서 60초 현상. 양성 PR이므로 노광된 Active 영역이 제거되고 Field 보호 PR은 남음.
7. 계측기에서 패턴 검사: 열린 영역 PR 잔사, 보호 PR, 정렬 오차, 접착 불량 가정 면적.
8. 정상은 확인 서명. 결함은 인지 체크 후 서명해 계속하거나, BOE 전에 코터로 가서 포토 재작업.
9. 습식 식각기에서 BOE 시간 입력. 권장 초기 시간은 실제 Field 두께 / 80 nm/분 × 1.1. 기준 두께에서는 약 5.16분.
10. 계측기에서 Active 잔류 산화막, Field/결함부 산화막, 언더컷, 미식각/정상/과식각을 검사하고 서명.

BOE 완료 뒤 스테이지 4의 PR 제거로 이어집니다.

## 실수와 재작업

- HMDS 생략: 접착 지수 1 → 0.55. 기준 현상에서 18%의 박리 면적을 가정합니다. BOE 중 이 영역의 Field 산화막도 공격받습니다. 이는 실제 수율 예측이 아닌 결정론적 교육 모델입니다.
- 회전수 증가: PR 두께가 rpm의 제곱근에 반비례하여 감소합니다.
- 노광 부족/짧은 현상: Active 개구에 PR 잔사. BOE는 잔사를 먼저 소모한 뒤 산화막 식각을 시작하므로 미식각 증가.
- 과다 노광/긴 현상: 보호 PR 손실 증가.
- 정렬 불량: 정렬 오차가 현상 검사와 BOE 합격 판정에 누적. 단면은 개념도이며 오차 수치를 별도로 표시합니다.
- 짧은 BOE: Active 산화막이 남음. 측정 후 추가 시간만 입력하여 누적 식각 가능.
- 긴 BOE: 산화막 개구가 뚫려도 언더컷과 과식각 지표가 증가. 시간을 더한다고 복구되지 않음.
- BOE 전 코터의 ‘PR 제거 후 포토 재작업’: 산화막 보존, HMDS부터 재시작. 이전 이력을 보존하고 재작업 5점을 감점 예약 상태로 기록.
- 현재 마스크 식각 후 포토 재작업은 차단. 과식각이나 이미 손상된 Field 복구는 이 범위에서 미구현. 새 Lot으로 다시 시작할 수 있음.
- 결함 인지 서명은 결과를 합격으로 바꾸지 않음. 검사 pass=false, 결함 수치와 인지 서명을 그대로 저장함.

결함 검사 실패와 재작업 감점은 11번 최종 등급 점수에 반영됩니다.

## 물리 모델과 검증 필요 항목

모든 모델 상수·출처는 `src/constants.js`.

- 산화: Deal–Grove `x²+Ax=xᵢ²+Axᵢ+Bt`. Illinois ECE444의 건식/습식 계수, Si(100) 보정. 초기 2 nm는 교육용 가정(검증 필요). 920~1100°C. 초기 건식 성장 보정·압력 변화·승온/냉각 미반영.
- 코팅: `h=1500*(3000/rpm)^0.5 nm`. 역제곱근 경향은 MicroChemicals 자료. 기준 PR 두께/회전수는 사용자 승인 교육용 보정(제품 지정 전 검증 필요).
- 노광·현상: 기준 PR의 노광량에 상대적인 현상 속도 × 시간. 보호부의 느린 침식, HMDS에 따른 결함 면적을 별도로 계산. 100 mJ/cm²·60초 및 속도/접착 계수는 검증 필요.
- 정렬: 평행이동 크기 + 회전 기준 길이의 절반 × |sin θ|를 최대 오차 근사값으로 사용. 첫 Active 마스크의 기준 마크를 가정한 연습이며 실제 첫 레벨 정렬 공정과 허용치는 검증 필요.
- BOE: 실온 6:1 BOE 약 80 nm/분은 Georgia Tech 교육 레시피 참고. 실제 장비 식각률 검증 필요. SiO₂:PR 선택비 20:1과 과식각 20% 경계는 교육용 가정(검증 필요).
- BOE 언더컷은 등방성 식각 거리(80 nm/분×누적시간)로 근사. 개구폭 감소, Si 식각, 욕 농도 변화는 미반영.
- 단면: Active/Field/PR 재료를 HTML/CSS로 표현. 수직·수평 스케일은 서로 다르며 실제 간섭색·계면 Si 소모 이동은 미표시. 박리는 별도 결함 면적으로 표시.
- 계측: 모델 결과를 검사 기록으로 복사. 산화막 두께는 0.1 nm 반올림. 실제 장비 노이즈는 미구현.

3D는 공정 계산을 모릅니다. 시스템은 Three.js/DOM을 import하지 않습니다. 공정 입력·정렬·단면·Runsheet는 HTML/CSS. `process_flow.json`의 autoAdvance(소작업 자동 진행), measurementType(pattern/etch), acceptDefects(인지 서명 허용)로 이번 순서를 정의합니다. 새 물리 모델은 코드 추가가 필요합니다.

저장 키를 유지하므로 기존 2단계 완료 기록은 Active HMDS부터, 3단계 완료 기록은 게이트 산화 준비부터 이어집니다. 같은 브라우저·주소·포트(origin)에서 복원됩니다. 저장 접근 실패 시 경고 후 현재 창에서 계속 진행합니다. ‘입구로’는 캐릭터 위치만 바꾸며, Runsheet ‘새 Lot’은 현재 기록을 초기화합니다.
